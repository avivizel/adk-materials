# מענה — טיפול בהתמכרויות בישראל

מאגר מידע מובייל-ראשון בעברית (RTL) לאיתור שירותי טיפול בהתמכרויות בישראל — שירותים ציבוריים ומסגרות פרטיות מפוקחות.

## מטרה

האפליקציה עוזרת לאנשים בישראל למצוא מענים לטיפול בהתמכרויות — לפי סוג התמכרות, אזור, סוג טיפול ואוכלוסיית יעד. המידע שקוף, עם מקורות רשמיים ומידע על פיקוח.

**זהו לא כלי אבחון רפואי.**

## הגדרות

### שירות ציבורי
שירות שמופעל ישירות על ידי משרד ממשלתי, רשות מקומית, קופת חולים או בית חולים ציבורי.

### מסגרת פרטית / מלכ״ר מפוקחת
מסגרת שאינה שירות ממשלתי ישיר אך מופיעה כמורשית, מפוקחת, מתקשרת או מופעלת במיקור חוץ על ידי גוף ממשלתי.

## מקורות נתונים

- משרד הבריאות (gov.il)
- משרד הרווחה והביטחון החברתי
- רשויות מקומיות
- קופות חולים
- בתי חולים ציבוריים
- מאגר אשפוזיות גמילה של משרד הבריאות

## הרצה מקומית

```bash
npm install
npm run dev
```

פתח [http://localhost:3000](http://localhost:3000)

## אימות נתונים

```bash
npm run validate:data
```

## בדיקות

```bash
npm test
npm run test:e2e
```

## בנייה

```bash
npm run build
npm start
```

## מבנה הפרויקט

```
src/
  app/           — דפי Next.js (בית, חיפוש, מפה, פרטים, שמורים, אודות)
  components/    — רכיבי UI
  data/          — מאגר JSON
  lib/           — לוגיקת חיפוש, סינון, מועדפים
  types/         — הגדרות TypeScript
  tests/         — בדיקות יחידה
e2e/             — בדיקות Playwright
scripts/         — סקריפט אימות נתונים
```

## פרטיות
